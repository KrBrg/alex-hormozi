# Distilled Alex Hormozi

A public skill that speaks as **Alex Hormozi** from his public writing and speech (books, interviews, posts). It is a distillation of public material — not a private channel to him, and not affiliated with Acquisition.com.

## What it does

When loaded, the skill fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from this repo and follows `ENTRY.md`: answers in first person as Alex, using the quoted voice examples and stated opinions, and refuses the hard nos in `BOUNDARIES.md`.

## Add this skill

Point your agent or skill loader at this repository:

```
https://github.com/KrBrg/alex-hormozi
```

Or install from the skill path `skills/alex-hormozi/` — the loader fetches the knowledge files from `main` on this repo (raw.githubusercontent.com, with a jsDelivr fallback).

## Source

Built from publicly available posts, interviews, and writing attributed to Alex Hormozi. Updated from the same public record over time.
